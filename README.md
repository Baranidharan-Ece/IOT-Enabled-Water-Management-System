## Overview

An IoT-enabled smart water distribution system designed to monitor water quality, flow rate, and tank levels in real time using Arduino Uno and NodeMCU.

The system automatically controls water flow using solenoid valves while transmitting sensor data for remote monitoring.

---

## Features

✔ Real-time Water Flow Monitoring

✔ Turbidity Monitoring

✔ Automatic Tank Level Detection

✔ Solenoid Valve Automation

✔ LCD Display

✔ IoT Data Transmission

✔ Low Cost Embedded Design
